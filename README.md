# 青鋒夜玄：俠影之戰

純前端 Canvas 生存動作小遊戲。玩家選擇角色後，在直向畫面中移動、施放掌技與氣彈，抵擋逐步增強的敵人與 Boss。

## 專案結構

- `index.html`：遊戲畫面、HUD、角色選擇、技能表與觸控控制。
- `style.css`：版面、手機觸控 UI、升級卡、技能選單與遊戲結束畫面樣式。
- `game.js`：遊戲主邏輯，包含角色、敵人、關卡、技能、音效、背景、輸入與主迴圈。
- `assets/`：角色、特效與背景圖片素材。

## 執行方式

直接用瀏覽器開啟 `index.html` 即可遊玩，不需要安裝套件或執行建置流程。

## 操作

- `WASD`：移動
- `J`：掌技
- `K`：氣彈
- `P`：技能表
- `R`：遊戲結束後重新開始

手機或觸控裝置會顯示虛擬搖桿與動作按鈕。

## 目前狀態

此專案沒有 npm 設定、測試框架或打包流程。若要做較大的重構，建議先補上基本回歸檢查，再逐步拆分 `game.js`。
