# 青鋒夜玄：俠影之戰

武俠風倖存者類（survivor-like）動作遊戲。操控俠客在無界戰場上迎戰無盡魔物，
自動攻擊配合手動掌技／氣勁，升級抽卡、技能商店、技能進化，一路推進 12 個關卡並擊敗最終魔王。

## 技術架構

- **純靜態網頁**：無建置流程，以本機伺服器開啟即可遊玩（例如 `python3 -m http.server` 後瀏覽 `index.html`；ES modules 需經 http 協定載入）。
- **渲染**：Three.js 2.5D（WebGL）——俯角透視相機、程序化地形 shader、五場景（楓落古鎮／雪月神居／浮空遺境／紫雷絕壁／血焰魔域）、
  InstancedMesh 場景道具、GPU 粒子、UnrealBloom 輝光與色調後製。Three.js 已 vendored 於 `lib/`，玩家端零外部網路依賴。
- **場景背景相片（可選）**：將 9:16 直式圖放入 `assets/backgrounds/`（`autumn.jpg`／`snow.jpg`／`floating.jpg`／`storm.jpg`／`inferno.jpg`）
  即以全螢幕照片呈現該場景並自動隱藏程序化地形；檔案缺席時自動退回程序化場景，零風險。
- **遊戲邏輯**：`game.js`（世界座標 2D 邏輯——碰撞、數值、關卡、輸入、UI DOM）。
- **渲染引擎**：`engine3d.js`（每幀將遊戲狀態同步到 3D 場景並渲染）。
- **音訊**：Web Audio 程序化合成——多聲部 BGM（旋律／低音／鼓組／pad，依場景換調式、依關卡分層強度）與全套音效，無音樂檔案。

## 操作

| 平台 | 移動 | 掌技（必殺） | 氣勁 | 技能表 |
|------|------|------|------|--------|
| 鍵盤 | WASD | J | K | P |
| 觸控 | 浮動搖桿（左半屏任意按壓） | 右下大鈕 | 右下小鈕 | 右上 ⚙ |

- 觸控搖桿為**浮動式**：左半邊畫面任意位置按下即出現搖桿並立即生效，放開後歸位。
- 攻擊鈕支援**按住連發**：壓住不放，冷卻一到自動再次施放，無須連點。
- 遊戲結束後按 `R`（或點攻擊鈕）重新開始。

## 特色系統

- 三位角色（青鋒／夜玄／霜凜）：攻防血閃屬性與掌技各異。
- 12 關卡＋5 場景輪換轉場演出，最終關魔王戰與勝利結算，之後進入無盡模式。
- 升級抽卡、技能商店（內力珠經濟）、**技能進化**（滿級技能＋指定升級卡達標時出現金色進化卡）。
- 菁英怪詞綴（疾速／分裂／爆炸）、Boss 寶箱三選一。
- **狂狼之力（擊殺疊狂）**：擊殺敵人疊加傷害層數、限時維持——持續殺戮保持狂化，手感回饋即時。
- **試煉系統**：每局結算將內力珠依比例轉為「修為」，於選角畫面**解鎖更高難度試煉階**（敵血敵傷上調、
  分數與掉落加成，localStorage 保存）——不賣數值，只賣挑戰。
- **詛咒祭壇**：第 3 關起每關出現暗紫祭壇，可自願接受隨機詛咒（敵人更強）換取即時內力珠、
  分數與其後掉落加成的 risk-reward 迴圈。
- 本地最佳紀錄（分數／關卡／存活時間）。
