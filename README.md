# 青鋒夜玄：俠影之戰

武俠風倖存者類（survivor-like）動作遊戲。操控俠客在無界戰場上迎戰無盡魔物，
自動攻擊配合手動掌技／氣勁，升級抽卡、技能商店、技能進化，一路推進 12 個關卡並擊敗最終魔王。

## 技術架構

- **純靜態網頁**：無建置流程，以本機伺服器開啟即可遊玩（例如 `python3 -m http.server` 後瀏覽 `index.html`；ES modules 需經 http 協定載入）。
- **渲染**：Three.js 2.5D（WebGL）——俯角透視相機、程序化地形 shader、三場景（沙漠黃昏／竹林夜月／古城遺跡）、
  InstancedMesh 場景道具、GPU 粒子、UnrealBloom 輝光與色調後製。Three.js 已 vendored 於 `lib/`，玩家端零外部網路依賴。
- **遊戲邏輯**：`game.js`（世界座標 2D 邏輯——碰撞、數值、關卡、輸入、UI DOM）。
- **渲染引擎**：`engine3d.js`（每幀將遊戲狀態同步到 3D 場景並渲染）。
- **音訊**：Web Audio 程序化合成——多聲部 BGM（旋律／低音／鼓組／pad，依場景換調式、依關卡分層強度）與全套音效，無音樂檔案。

## 操作

| 平台 | 移動 | 掌技（必殺） | 氣勁 | 技能表 |
|------|------|------|------|--------|
| 鍵盤 | WASD | J | K | P |
| 觸控 | 左下搖桿 | 右下大鈕 | 右下小鈕 | 右上 ⚙ |

遊戲結束後按 `R`（或點攻擊鈕）重新開始。

## 特色系統

- 三位角色（青鋒／夜玄／霜凜）：攻防血閃屬性與掌技各異。
- 12 關卡＋3 場景輪換轉場演出，最終關魔王戰與勝利結算，之後進入無盡模式。
- 升級抽卡、技能商店（內力珠經濟）、**技能進化**（滿級技能＋指定升級卡達標時出現金色進化卡）。
- 菁英怪詞綴（疾速／分裂／爆炸）、Boss 寶箱三選一。
- **修煉系統**：每局結算將內力珠依比例轉為永久「修為」，於選角畫面購買永久加成（localStorage 保存）。
- 本地最佳紀錄（分數／關卡／存活時間）。
